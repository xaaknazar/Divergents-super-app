Дата: 20 октября 2026. Автор дизайна: Claude (Cowork), холст Claude Design.
Холст (смотреть глазами): https://claude.ai/artifact/KDZjhiC3DyuAaS2RseJfAM — страницы «Экраны», «Компоненты (Storybook)», «Reading challenge».

Что лежит в этой папке:

| Папка | Что внутри |
| --- | --- |
| `HANDOFF.md` | Этот файл: промпт для Claude Code и спецификация |
| `screens/` | Рендеры всех экранов холста (JPEG, 2x). Номер в имени — порядок на холсте |

## 1. Промпт для Claude Code (скопировать целиком)

```
Ты работаешь в репозитории мобильного приложения Divergents (React Native, Expo SDK 54, TypeScript).
Задача: перенести в приложение согласованный дизайн из папки docs/design-handoff-2026-10-20/
(файл HANDOFF.md, рендеры в screens/, исходники прототипа в design-source/*.dc.html).

Порядок работы:
1. Прочитай HANDOFF.md полностью. Для каждого пункта открой рендер в screens/ и исходник
   в design-source/<Компонент>.dc.html — там точные значения (цвета, размеры, отступы, тексты, состояния).
2. Создай ветку design/handoff-2026-10-20. Работай фазами из раздела 7, один коммит на фазу.
3. Сначала сопоставь компоненты прототипа с существующими в src/components (таблица в разделе 6).
   Если компонент уже есть — меняй его, а не создавай дубликат.

Обязательные правила архитектуры (не нарушать):
- Весь визуальный стиль живёт внутри компонента. Снаружи — только семантические props
  (variant / size / tone / state / scheme) и раскладка через Wrapper.
- Никаких внешних style / className overrides и props, повторяющих CSS (color, padding и т.п.).
- Каждый компонент — плоско в src/components. Экраны только собирают компоненты.
- Для каждого нового или изменённого компонента — stories со всеми состояниями (светлая и тёмная
  тема, крупный шрифт) и npm run storybook:generate.
- Значения — через src/theme/tokens.ts и ThemeContext. Новые значения оформлять токенами
  (например shadows.tappable), а не числами в компонентах.
- Не менять бизнес-логику, API, подсчёт рейтингов, права доступа и тексты правил Reading.
  Если дизайн требует новых данных (например имя капитана в карточке команды) — не выдумывать,
  а выписать в отчёт как «нужны данные».
- Раздел «Карьера» не трогать.
- Шрифт Gotham Rounded: неразрывный пробел U+00A0 в нём рисуется шириной около 325 px.
  Никогда не выводить U+00A0 (в т.ч. из Intl.NumberFormat / toLocaleString('ru')). Использовать
  узкий U+202F или обычный пробел + numberOfLines/nowrap. Проверить цены, числа, «&nbsp;».

Проверка после каждой фазы: npx tsc --noEmit, npm test, npm run storybook:generate.
Скриншоты изменённых экранов из симулятора сравнить с рендерами в screens/.

В конце дай отчёт по каждому изменённому файлу: что было плохо → что перенесено внутрь
компонента → какие props добавлены/упрощены → что удалено из API → почему стало чище.
Отдельным списком: отклонения от макета и причины, новые потребности в данных/API, открытые вопросы.
```

Положите эту папку в репозиторий как `docs/design-handoff-2026-10-20/` (или поправьте путь в промпте).

## 2. Общие изменения (действуют во всём приложении)

### 2.1 Таб-бар (`TabDock`) — согласовано
Рендер: любой экран с таб-баром, например `screens/04_community/01_CommunityHome.jpg` (низ экрана).
Исходник: `design-source/TabDock.dc.html`, палитра `navy`.

- Плавающая стеклянная панель: слева/справа 14, снизу 24 (+ safe area), внутренний отступ 4, **радиус 24** (не «таблетка»).
- Фон: градиент сверху вниз `rgba(255,255,255,0.58)` → `rgba(244,246,251,0.42)`, blur 28, saturate 190 %; рамка 0.5 `rgba(255,255,255,0.75)`; тень `0 10 30 rgba(35,64,136,0.14)` + `0 2 6 rgba(16,29,44,0.05)`.
- Пять вкладок, промежутков между ячейками нет. Каждая ячейка — flex 1, высота 60.
- **Выбранная вкладка: подсветка заполняет всю ячейку целиком, радиус 18** (концентрично панели), фон `rgba(35,64,136,0.10)` + внутренняя линия 0.5 `rgba(35,64,136,0.12)`. Иконка solid `#234088`, подпись 11/14 bold `#234088`.
- Невыбранные: иконка line `#8A8F98`, подпись 11/14 medium `#8A8F98`.
- Если в коде панель уже «приподнятая капсула» — сохранить её поведение, поменять только форму выделения и радиусы.

### 2.2 Кнопка профиля (`ProfileButton`, в коде `ProfileAvatarButton`) — на всех вкладках
Исходник: `design-source/ProfileButton.dc.html`, рендер `screens/12_components/*ProfileButtonStories.jpg`.
- Зона 52×52. Лицо 42: градиент 140° `#3D5BDB` → `#234088`, внутренняя белая обводка 2, инициалы bold 17 белые (или фото).
- Вокруг — кольцо заполненности анкеты: трек `rgba(35,64,136,0.14)`, прогресс `#234088`, толщина 2.5. Скрыто при 0 и 100 %.
- Бейдж событий: красный `#FF3B30`, min 18, белая обводка 2, «9+» при > 9.
- `variant="floating"` — стеклянный круг для Карты (белый 72 % + blur 20 + тень).
- Стоит в шапке каждой вкладки: Обучение, AI, Сообщество, Карта (floating), Карьера. Ведёт в Профиль.

### 2.3 Фон шапки вкладок (`HeaderBackdrop`) — согласовано
Исходник: `design-source/HeaderBackdrop.dc.html` (там функция, которая строит SVG). Рендер: `screens/12_components/*HeaderBackdropStories.jpg` и верх экранов вкладок.
- Только на корневых экранах вкладок: Обучение, AI, Сообщество, Профиль. Карта (там карта) и Карьера — без фона.
- Слой за контентом, высота 360, не перехватывает касания.
- Заливка: `radial(90%×80% в правом верхнем углу, rgba(61,91,219,0.20) → 0 на 70 %)` + `radial(70%×60% в левом верхнем, rgba(35,64,136,0.12) → 0)` + вертикальный градиент `#DDE5F6 → #E7ECF8 (45 %) → #F2F2F7`. Плавно исчезает к низу (маска: 100 % до 45 %, 0 % к 100 %).
- Поверх — тонкий линейный рисунок (линии 1.1–1.2, navy, прозрачность 0.06–0.17), исчезает быстрее (маска 22 % → 78 %):
  - Обучение — «расходящиеся пути»: 10 кривых из одной точки внизу слева веером вправо вверх + 4 точки;
  - AI — орбиты: 7 концентрических кругов вокруг (330, 30) + 4 «искры»;
  - Сообщество — сеть: 10 узлов и 13 связей в правом верхнем углу;
  - Профиль — 8 контурных эллипсов, повёрнутых на −18°, вокруг (330, 40).
- Реализация в RN: `react-native-svg` (рисунок 390×360 по координатам из исходника, масштабировать по ширине экрана) + `expo-linear-gradient`; маску сделать градиентным оверлеем цвета фона или через `@react-native-masked-view/masked-view`. При Reduce Transparency — оставить только заливку.

### 2.4 Тень у кликабельных блоков — выбрано «мягкая тень»
Сравнение: `comparisons/blocks-before-after.png`.
- Всё, что открывает экран, получает одну тень. CSS-значение: `0 1px 3px rgba(16,24,40,0.08), 0 12px 28px -10px rgba(16,24,40,0.28)`.
- В RN завести токен `shadows.tappable` ≈ `shadow({ color: '#101828', opacity: 0.16, radius: 14, y: 10, elevation: 5 })`. Подобрать на устройстве так, чтобы совпало с рендером.
- Применяется к: активный челлендж, «Открыт набор», «Мои активности», канал, поездки, спорт, «Продолжить» (обучение), плитки «Скачанные/Библиотека», карточки курсов, карточка Reading.
- Статичные группы (списки ListSection, плашка анкеты, правила) — плоские.
- В горизонтальных лентах карточек добавить снизу 24, чтобы тень не обрезалась.

### 2.5 Цветная плашка иконки (`IconTile`) — новый компонент
Исходник: `design-source/IconTile.dc.html`, рендер `screens/12_components/*IconTileStories.jpg`.
- Размеры 36 / 44 / 52, радиус = 0.3 × размер. Иконка solid 20 / 24 / 28.
- `variant="solid"`: градиент 155° светлый → основной тон, белая иконка, блик `inset 0 1 0 rgba(255,255,255,0.32)`, низ `inset 0 −1 0 rgba(0,0,0,0.08)`, цветная тень `0 6 14 −6 rgba(тон, 0.6)`.
- `variant="soft"`: фон `rgba(тон, 0.11)`, иконка цвета тона.
- Тоны (светлый → основной): brand `#5672E6→#234088`, challenge `#FF9A4D→#E8590C`, trip `#3CCB82→#15803D`, sport `#7B90FF→#3D5BDB`, violet `#A587FF→#6D3FD6`, orange `#FFAE5C→#C2410C`, pink `#FF7AB6→#BE185D`, neutral `#9A9AA2→#5C5C60`.

### 2.6 Прочее общее
- `StatusBadge` получает `variant="frosted"` — белая «таблетка» `rgba(255,255,255,0.78)` с текстом цвета тона, для цветных фонов.
- `SearchField` получает `surface="raised"` — белое поле (на фоне шапки вкладки).
- Горизонтальные строки разделов (`SectionTabs`/чипы) при открытии прокручиваются так, чтобы выбранный пункт был виден.
- **Навбар внутренних страниц без фона:** у `NavHeader` (inline, вариант по умолчанию) убрана белая подложка и нижняя линия — кнопка «Назад», заголовок и действия лежат прямо на фоне страницы. Белая плашка остаётся только у полноэкранной модалки.
- **Иконка «бегущий человек»** (`person-running`): в наборе Layero Round её нет, поэтому глиф нарисован вручную в том же стиле (solid и line, viewBox 24). Путь — в `design-source/Icon.dc.html` (ключ `"person-running"`). В RN добавить как SVG-иконку набора. Используется: шапка «Мои тренировки», кнопка «Записать бег», карточка «Мои тренировки» в Профиле, рекорд «Самая длинная пробежка», «Утренняя пробежка» в Профиле и в «Сообществе → Спорт».

## 8. Приёмка
- Скриншот каждого изменённого экрана в светлой теме совпадает с рендером по композиции, цветам, размерам и текстам; тёмная тема и крупный шрифт не ломают раскладку.
- Ни один компонент не принимает внешние style/className; у каждого изменённого компонента есть stories.
- Нигде не выводится U+00A0 (цены «4 000 ₸» не разъезжаются).
- `tsc`, тесты и `storybook:generate` проходят.
- Отчёт по файлам и список «нужны данные / открытые вопросы» приложен.
