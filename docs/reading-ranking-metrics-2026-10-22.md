# Reading: рейтинг по темпу и общему числу страниц

Статус: реализовано локально, не опубликовано. Номер сборки не менялся.

## Что изменилось

Запрос: сохранить учёт среднего темпа и также ранжировать по общему числу
прочитанных страниц. Чтобы не вводить произвольные веса двух показателей,
добавлены два самостоятельных режима одного списка:

- **Средний темп** (по умолчанию): `averagePages DESC`, затем
  `daysParticipated DESC`, затем `userId ASC`. Прежний порядок сохранён.
- **Всего страниц**: `pages DESC`, затем `averagePages DESC`, затем
  `daysParticipated DESC`, затем `userId ASC`.

Все участники получают последовательные места с первого дня. Никакого
повторного десятидневного порога, проверки результатов или смешанного балла
не вводится. Переключение рейтинга не меняет страницы, таймер, флаги или участие.
При полной ничьей ID нужен только для стабильного порядка, как раньше.

## Данные

Сервер уже отдаёт полный approved-список `detail.ranking` без пагинации.
`pages` — подтверждённые страницы по всем книгам за весь личный период
участия в этом челлендже, включая сегодняшний день. Это не только сегодняшние
страницы, не сумма локальных черновиков, не повторное сложение `shelfBooks`.

`averagePages` приходит с сервера; его делитель — календарные дни участия,
включая пропуски. Сортировка использует значения до форматирования для экрана.
Массив ответа не изменяется: сортируется копия.

Для этого изменения рейтинга серверный релиз и миграция не нужны. Отдельное
обновление постоянной полки из `reading-bookshelf-and-allowed-apps-2026-10-22.md`
по-прежнему требует серверной миграции перед выпуском общей мобильной сборки.
Серверная сортировка старых командных/scheduled-челленджей не менялась.

## Интерфейс и компоненты

- `ReadingRankingContent`: существующий `Segmented`, два подписанных режима;
  выбор сохраняется при обновлении данных текущего экрана.
- `ReadingRankRow`: всегда видны оба показателя. `metric` задаёт визуальный
  акцент; `pages` обязательный. VoiceOver читает оба значения. Длинные имена
  и большие числа могут переноситься; внешних косметических пропсов нет.
- `ReadingRankLink`: явно подписаны оба личных места; карточка остаётся
  непосредственно над «Мои книги и история» и открывает рейтинг.
- `ReadingProgressSummary`, правила и описание создания больше не утверждают,
  что единственный критерий — средний темп.
- Storybook: оба режима, разные лидеры, пустой список, тёмная тема,
  крупный шрифт, длинные имена и большие числа.

Mobile App Design Standards использован для повторного применения системного
переключателя, понятных единиц измерения, переноса текста и доступности.
