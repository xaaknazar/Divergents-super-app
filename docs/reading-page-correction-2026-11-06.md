## Поведение

1. Форма объясняет, что вводится количество страниц за подход, а не номер страницы книги. Ноль допустим. Десятичное/некорректное значение не превращается в другое число и не сохраняется.
2. При большом значении появляется явное подтверждение. Читатель может исправить число либо подтвердить. Триггер: от 200 страниц либо более `max(30, минуты × 3)`. Это защита от опечатки, не модерация и не запрет быстро читать.
3. В своей истории доступна кнопка «Исправить страницы за сегодня и вчера». По каждому подходу видны книга, дата/время по Алматы, страницы, минуты. Исправляются только страницы; время, флаги и завершённость не меняются.
4. Успех показывается только после ответа сервера. При потере ответа повторяется тот же operationId. Число в форме сохраняется при ошибке. Конфликт с другим устройством обновляет историю и требует нового явного сохранения.
5. Старый сервер не показывает новую функцию; чужая история доступна только для просмотра. Возвращение на экран челленджа обновляет его через существующий focus refresh.
