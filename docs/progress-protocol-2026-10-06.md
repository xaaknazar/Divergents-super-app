# Сохранение отметок v2

> Разбор несовместимости build 85 с рабочим сервером и исправления 8 октября:
> [progress-incident-2026-10-08.md](progress-incident-2026-10-08.md).

Внедрены номера операций, версии, проверка серверной квитанции и постоянная
очередь с привязкой к аккаунту. Протокол описан в соседнем серверном репозитории:
`divergents-lms/docs/progress-protocol-2026-10-06.md`.

Ключ `dvg.challengeProgressOutbox.v2` очищается при выходе из аккаунта.
Данные очереди обязательно записываются через saveJSON(..., {strict:true})
до сетевого запроса. При конфликте старый ввод не отправляется повторно
с новой версией. Пользователь видит ошибку, а не «сохранено».

Нужна новая мобильная сборка и координированный серверный релиз с миграцией.
Сборка/TestFlight/production в рамках этой правки пока не выполнялись.
