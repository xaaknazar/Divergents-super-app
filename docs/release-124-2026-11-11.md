## Изменение

Раньше подтверждение записи книги показывалось как успешное добавление, даже
если следующий запрос полки завершался ошибкой или не содержал книгу.
Теперь после квитанции выполняется чтение полки с одним повтором при отсутствии
книги. Успех возвращается только для найденной непрочитанной книги с ключом
из серверной квитанции. При сбое форма сохраняет введённую книгу; повторная
попытка использует прежний operationId. Прочитанную книгу приложение предлагает
вернуть через историю. Успешное добавление обновляет остальные подписанные полки.

Это исправление ложного подтверждения и восстановления после сбоя чтения.
Причина отсутствия книги у конкретного участника не подтверждена диагностикой
его аккаунта. Постоянное отсутствие книги в ответе сервера требует отдельной
серверной проверки. Пользовательские записи не изменялись.

и запустить подход. Повторить добавление при потере сети: форма не должна
исчезать с ложным успехом. Для прочитанной книги должно появляться объяснение.
