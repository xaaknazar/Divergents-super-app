**Про возрастной рейтинг.** В анкете на всё отвечать «Нет/Отсутствует». Один

постами**. Если Apple посчитает это пользовательским контентом без модерации,
рейтинг поднимут до 12+ и попросят описать модерацию. Честный ответ: контент
создают только пользователи с правами, каналы модерируются владельцем и
администраторами, есть жалобы и блокировка. Готовься это описать.

| Поле | Значение |
|---|---|
| URL службы поддержки | `https://divergents-lms.kz/support` — **после того как страницу сделают** |

Главную сайта в поддержку ставить нельзя — ревьюер открывает ссылку и ищет
контакты. Это частая причина отклонения.

Файл зоны покрытия не трогать — он только для навигационных приложений.

## 7. Анкета App Privacy

Заполняется отдельно, до отправки. Отвечать по факту — перечень должен совпадать
с политикой на сайте.

**Собираем и связываем с личностью:**

| Категория | Что именно | Зачем |
|---|---|---|
| Contact Info | имя, фамилия, почта, телефон | Аккаунт, поддержка |
| User Content | фото профиля, фото мест, отзывы, комментарии, голосовые | Функциональность |
| Identifiers | ID аккаунта, push-токен | Аккаунт, уведомления |
| Usage Data | прогресс по курсам, отметки челленджа | Функциональность |
| Location | примерное местоположение | Карта и маршруты |
| Sensitive Info | результаты Gallup, MBTI, Гарднера, психологические отчёты | Подбор рекомендаций |
| Diagnostics | сбои и производительность | Стабильность |

**Used for tracking: НЕТ** по всем пунктам — рекламы и трекинга между
приложениями в проекте нет.

Отдельно готовься объяснить **Sensitive Info**: данные вводит сам пользователь,
используются только для рекомендаций внутри сервиса, третьим лицам в
рекламных целях не передаются.

## 8. Информация для проверки (App Review Information)

**Демо-аккаунт обязателен** — приложение без входа ничего не показывает.

Проблема: вход по коду на почту, ревьюер не имеет доступа к чужому ящику.
Решение до отправки: завести ящик вроде `appreview@divergents-lms.kz`, заполнить
у него анкету и выдать доступ к купленному курсу, а в заметках дать доступ к
веб-почте.

Заметки для ревьюера (вставить, подставив данные):

```
Вход выполняется по одноразовому коду, который приходит на почту.
Демо-аккаунт: appreview@divergents-lms.kz
Доступ к почте для получения кода: <адрес веб-почты>, логин / пароль
Также доступен вход через Sign in with Apple.

Приложение бесплатное и не содержит встроенных покупок. Курсы приобретаются
на сайте divergents-lms.kz; в приложении открываются уже приобретённые и
бесплатные курсы. Ссылок и кнопок покупки в приложении нет.

Пользовательский контент (каналы, отзывы о местах) модерируется: создавать
каналы могут только пользователи с правами, есть жалобы и блокировка.

Геолокация используется только на экране карты, для показа ближайших мест и
построения маршрута.
```

Контактные данные: твоё имя, телефон с кодом страны, рабочая почта.

## 10. Скриншоты

Обязательны два размера: **6.9″** и **6.5″**. По 3–10 штук, лучше 5–6.

Что показать: главная «Обучение» с курсами, экран курса с программой, урок с
видео, челлендж с рейтингом команды, профиль талантов с Gallup, карта сообщества.

Скриншоты с интерфейсом приложения, без рекламных коллажей поверх — Apple их
допускает, но лишние обещания на картинке проверяют строже.

## 11. Порядок

1. Разработчик делает `/support`, `/account-delete` и дополняет `/privacy`.
2. Я убираю кнопки покупки из приложения (правило 3.1.1).
3. Заводится демо-ящик, заполняется анкета и выдаётся доступ к курсу.
4. Собираем сборку 49, загружаем.
5. Заполняются поля из этой памятки + анкета App Privacy.
6. Скриншоты.
7. Отправка. Первая проверка обычно 1–3 дня.
