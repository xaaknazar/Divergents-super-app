# Локализация API и БД в Казахстане — проверка 12 октября 2026

Статус: диагностика и предложение. Тариф, DNS, конфигурация сервера и рабочие данные не изменены. Платный переход и окно возможного простоя не подтверждены.

## Проверенные факты

- Текущий VPS PS.kz Basic-2 находится в Алматы. На нём PostgreSQL Divergents, а также действующие службы Talentslab (MySQL, PHP, Nginx, почта, DNS, ispmanager). Их необходимо сохранить.
- API и веб-сайт Divergents сейчас работают на Vercel, регион функций Frankfurt (`fra1`). Между API и PostgreSQL есть международный сетевой участок.
- В кабинете текущий тариф: 20 100 ₸ за квартал, эквивалент 6 700 ₸/месяц, 80 400 ₸/год.
- Окно повышения тарифа предлагает Basic-3 за **39 730 ₸/квартал**: эквивалент 13 243,33 ₸/месяц и 158 920 ₸/год при неизменной цене. Разница: 19 630 ₸/квартал, 78 520 ₸/год. Это цена тарифа, не подтверждённая сумма счёта за переход посреди оплаченного периода. Доплату и состав итогового счёта нужно проверить до подтверждения.
- Публичная конфигурация Basic-3: 4 shared vCPU, 4 ГБ RAM, 80 ГБ SSD. Это не четыре гарантированно выделенных физических ядра. Документация PS.kz указывает гарантированный минимум 12,5% ресурса на vCPU при конкуренции.

## Минимальный предлагаемый вариант

1. После согласования тарифа увеличить **существующий** VPS до Basic-3 (4 ГБ RAM). Вторую VM, Kubernetes и балансировщик на этом этапе не покупать.
2. Разместить Next.js (сайт + API) на этом же VPS, подключить PostgreSQL через локальный PgBouncer/loopback. База остаётся на месте, международные API–БД обращения исчезают.
3. Сохранить `https://divergents-lms.kz` и API-контракты. Если URL и контракт не меняются, сам перенос не требует новой мобильной сборки. Это не отменяет необходимость обновлений клиента для отдельных уже известных ошибок синхронизации.
4. Выпускать только проверенный серверный релиз. Локальный `/Users/xaknazar/divergents-lms` содержит много посторонних незавершённых изменений и не является готовым артефактом для прямого деплоя. Последний ранее проверенный серверный релиз: `bf502e1f21da67a25279fde1fcc619bd38573e65`; перед переносом повторно сверить актуальный продакшен.

4 ГБ — кандидат для недорогого первого шага, а не гарантия достаточности на пике. Совместное размещение API и БД экономит деньги, но оставляет общую точку отказа.

## Обязательные условия переключения

- Резервная копия с проверкой восстановления и копия вне этой VM, также в Казахстане. Текущий локальный pg_dump не защищает от потери VM. Внешнее хранилище не подключено; его стоимость не включена в цену VPS.
- Сборка артефакта вне рабочего VPS; отдельный системный пользователь и сервис для Next.js; ограничение ресурсов, ротация логов, контроль свободного места и памяти.
- Адаптировать `@vercel/functions.waitUntil`, обработчик постоянной очереди прогресса и cron-задачи. На новом хосте должны работать надёжный worker/scheduler; во время перехода не должно быть двух одновременно активных отправителей уведомлений.
- Проверить TLS, Clerk, proxy headers, загрузку медиа, авторизацию, сайт и мобильный API. Не переносить секреты в мобильный репозиторий.
- На изолированных тестовых данных проверить параллельные челленджи, повтор/обрыв отправки отметки, идемпотентность, подтверждение только после записи в БД, фоновые задания и рейтинги. Не проводить нагрузочные записи по настоящим участникам.
- Измерить задержки p50/p95/p99, ошибки API, время SQL, очереди/повторы, RAM/swap/CPU под реалистичной нагрузкой, включая вечерний пик. Не обещать достаточность ресурсов по одному утреннему снимку.
- DNS переключать только после проверок. Сохранить предыдущий рабочий путь на Vercel для отката, не отменять услуги и не закрывать удалённый доступ БД, пока он нужен для отката. Изменение тарифа может потребовать перерыва; длительность и порядок уточнить до работ.
- Не запускать `prisma db push --accept-data-loss`. Для этой локализации миграция данных БД не нужна; схему без отдельной необходимости не менять.

## Граница «всё в Казахстане»

Этот этап локализует **наши сайт, API и PostgreSQL**. Clerk (вход), Mux (видео), UploadThing (медиа), push-сервисы Apple/Google остаются внешними. Полная замена этих сервисов — отдельный проект, она не входит в цену повышения VPS и не нужна для устранения международного участка API–БД. Мобильный интернет пользователя и его задержки также остаются.
