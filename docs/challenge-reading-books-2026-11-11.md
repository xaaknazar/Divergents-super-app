## Сценарий

В обычном Divergents Challenge кнопка ввода чтения открывает шторку «Чтение». Без книги страницы сохранить нельзя. Название и автор обязательны; автозамена выключена. Добавленная книга сразу выбирается, следующий отчёт открывает последнюю использованную активную книгу. ИИ здесь не требуется.

Главная форма: текущая книга → страницы сегодня по этой книге → «Я дочитал(а) эту книгу» → «Сохранить». Завершённая книга остаётся в раскрываемой истории с общим количеством записанных страниц. После завершения появляется «Выбрать следующую книгу». В тот же день можно читать несколько книг. Повторное сохранение редактирует число, а не прибавляет его повторно.

Старые страницы без книги сохранены отдельно. В таком дне поле называется «Новые страницы сегодня» и предупреждает не вводить старое число повторно. Старым результатам книги не приписываются.

Книга и страницы подтверждаются сервером вместе. До отправки команда записывается на телефон. Потерянный ответ повторяется с тем же идентификатором; при конфликте версий нет автоматической перезаписи. При сбое формы сохраняют ввод и не показывают успех. Нельзя использовать чужую книгу, писать за закрытый день или после завершения участия.

## Изменения

- `src/components/ChallengeReadingSheet.tsx` + stories: все визуальные состояния и интерактивный пример; light/dark/large text, пустая полка, история, ошибка и сохранение.
- `HalfSheet` + stories: большая шторка и адаптация к размеру текста; стили внутри компонентов.
- `src/state/useChallengeReadingBooks.ts`: загрузка, добавление, сохранение, восстановление неподтверждённой команды, изоляция аккаунтов.
- `src/data/challengeReadingBooks.ts`: строгая проверка ответа API и квитанции с книгой; данные не подменяются выдуманными.
- `src/data/community.ts`: категория задачи из API.
- `src/screens/community/ChallengeDetailScreen.tsx`: новый ввод только для чтения. Спортивные задачи, команды, баллы, дедлайны и Extreme/Moderate не переделывались.
- `.rnstorybook/index.tsx`: только в предпросмотре скрыто известное предупреждение notifications старого dev client без keychain entitlement. Ошибки продолжат писаться в журнал Metro.

## Проверки и скриншоты

Нативный симулятор `Divergents Reading UI`, изолированный Storybook с демонстрационными книгами. Пройдено нажатиями: книга → завершить и сохранить → следующая → раскрыть историю → добавить книгу с названием и автором → записать страницы. Тёмная тема и увеличенный текст проверены визуально. Снимки в `docs/previews/challenge-reading/`.

Общий мобильный набор: 1328/1328 успешно. После последней правки ожидания авторизации и текстов ошибок повторно прошли 15 целевых тестов (форма, сохранение, API). TypeScript проходит. ESLint в мобильном проекте не настроен. `ui:audit`: 1808 старых замечаний, столько же в исходном 124; новых нарушений не добавлено.

Сервер: TypeScript, ESLint изменённых файлов, валидная Prisma-схема. 386 общих тестов прошло, 11 явно отключённых наборов пропущены. Отдельно 30 тестов на изолированном локальном PostgreSQL прошло без пропусков: новый учёт книг + существующий протокол прогресса.
