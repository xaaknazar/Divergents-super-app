## Изменения

- Активность в обычном челлендже вводится в нижней панели примерно на половину экрана.
  В ней выбираются упражнение и количество; шаги пересчитываются по действующим правилам.
- Йога/пилатес доступны только при женском поле серверной анкеты. Неизвестное поле не даёт эту опцию.
  Офлайн используется только ранее подтверждённое поле текущего аккаунта.
- Калькулятор начинает с текущего итога и прибавляет новые упражнения; предупреждает о повторном учёте
  активности из шагомера. Разбивка упражнений — черновик панели, на сервер сохраняется итог шагов прежним механизмом.
- Стеклянная кнопка сезона с системным шевроном открывает список текущих и завершённых сезонов.
  Выбранный прошлый сезон показывает итоговые рейтинги команд/участников и составы.
- Таблица прокручивается под плавающей шапкой с мягким краем вместо жёсткой прямоугольной границы.
- Новые компоненты имеют Storybook-примеры. Экранные API не принимают внешние косметические overrides.
