## 🔴 P1 — Уведомления и push (сейчас не работают вообще)
- [ ] `GET /api/mobile/notifications` отдаёт ленту с полем **`target { tab, screen, params }`** (spec §3.1).
- [ ] Сервер **создаёт** уведомления на события и шлёт **Expo push** (spec §3.2–3.3):
  - [ ] новый курс → всем/сегменту (`CourseDetail`);
  - [ ] новый пост/аудио в канале → **подписчикам канала** (`ServerChannel`);
  - [ ] новая вакансия под профиль → пользователю (`VacancyDetail`);
  - [ ] одобрение запроса в канал / оффер / статус отклика → адресату;
  - [ ] челлендж: старт и напоминание дня → участникам (`ChallengeDetail`).
- [ ] Push шлётся с `data.target` (тот же формат), тап открывает нужный экран.
- [ ] `POST /api/mobile/push/unregister { token }` — отписка при выходе (иначе адресация «протекает» между аккаунтами на одном устройстве). *(аудит #15)*
