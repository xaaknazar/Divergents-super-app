# История и итоги личных программ

## Поведение

- Профиль → Мои тренировки → История программ. Активные программы больше не смешиваются с завершёнными.
- После отметки нормы в последний день сразу открывается результат. Если открыты подробности программы, они превращаются в экран итогов внутри закрываемой шторки.
- Программа с пропущенными/частичными днями переходит в историю по окончании календарного срока. Обновление происходит в полночь и при возвращении приложения на передний план.
- История строится из существующих программ и журналов, без миграции или дублирования записей. Уже завершённые программы тоже доступны.
- Используется существующее локальное хранилище `dvg.fitness.v1`. Облачная синхронизация не добавлена; удаление данных приложения удаляет историю.
- Завершённый журнал доступен для просмотра, но не для новых отметок. Напоминания завершённой программы отменяются.

## Расчёт

- Общий результат — сумма фактически записанных значений за дни программы. Частичные результаты и превышения нормы учитываются полностью.
- Дни с нормой и дни с любой положительной активностью показаны отдельно.
- Лучшая серия — максимальная последовательность дней с выполненной нормой за весь период, не только серия в конце.
- Лучший день — максимальное записанное значение.
- Будущие записи, записи вне периода, отрицательные и нечисловые значения не увеличивают результат.
- Достижения конкретной программы: все дни с нормой, серия 3/7/14/21/30 дней, превышение цели. При частичной активности без этих достижений — нейтральное признание усилий, без выдуманных наград.
- Журнал раскрывается по кнопке; отсутствие записи не утверждает отсутствие физической активности.
- «Поделиться результатом» передаёт те же данные в существующий редактор карточки для сторис (PNG/системное меню отправки).

## Дизайн

Использованы UI/UX Pro Max и Mobile App Design Standards: визуальная иерархия с главным общим результатом, фирменная палитра, светлая/тёмная темы, адаптивные метрики, доступные подписи и состояния, безопасные отступы, явное закрытие шторки, область нажатия от 48 pt для новых действий. Новая библиотека или шрифт не добавлены.

## Проверки

- TypeScript и полный Jest-набор.
- Расчёты: 50 × 30 = 1 500, частичные дни, превышения, разрывы серии, некорректные записи, сортировка истории, последний день.
- Компоненты: история, пустые состояния/загрузка, передача результатов в редактор карточки, раскладка при ширине 320/375/812 и масштабе шрифта 2.
- Интеграция: финальная быстрая отметка → результат, обычная отметка без завершения, преобразование открытых подробностей в итог, закрытие и переход в историю.
- Хранилище: восстановление итогов после повторного монтирования, отмена напоминания, завершение в полночь.
- Визуально: реальный компонент итогов в изолированном Expo Go preview на iPhone 17e, светлая/тёмная тема, увеличенный текст и раскрытый журнал. Исправлен некорректный пробел-разделитель тысяч у Gotham Rounded на iOS.
- Системная отправка картинки получателю, Android-устройство и production-сборка в этой задаче не проверялись. Версия приложения не повышалась, публикация не выполнялась.
