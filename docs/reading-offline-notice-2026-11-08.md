# Reading: ложное «Нет интернета» при открытии

Причина: useReadingChallenge сначала восстанавливал сохранённый экран с stale=true, а applyLocalView автоматически связывал stale с offline. Поэтому при нормальной сети до первого ответа сервера на секунду появлялась плашка отсутствия интернета.

Теперь свежесть локальных данных отделена от состояния соединения. Чтение кэша не включает офлайн-плашку. Она включается после ошибки соединения при обновлении или перехода к подтверждённому офлайн-запуску; свежий ответ снимает её. HTTP-ошибки авторизации и сервера при открытии не считаются отсутствием интернета. Кэш, очередь, таймер и сохранение страниц работают по прежним правилам. Новых зависимостей/нативных разрешений нет.

Проверки: TypeScript PASS; useReadingChallenge + ReadingChallengeLayout — 101/101; readingOfflineMode + readingNextDay + useReadingResume — 65/65. Новые тесты фиксируют отсутствие плашки на ВСЕХ промежуточных отрисовках до успешного запроса, реальную сетевую ошибку, восстановление и HTTP 401/500. На физическом устройстве не проверено.

Изменение мобильное: подготовлено для следующей сборки после iOS 123. Сервер не менялся; новая IPA в рамках этой правки не загружалась.
