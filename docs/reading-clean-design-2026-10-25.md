# Reading: более чистый экран участника

25 октября 2026. Ветка `design/reading-clean` (от `fix/reading-start-recovery`). Только интерфейс:
логика, API, тексты правил, расчёт рейтинга и порядок блоков, согласованный в iOS 97
(таймер → действие → книга → «Сегодня» → «Мой рейтинг» → «Мои книги и история»), не менялись.
Не опубликовано; новая нативная сборка не нужна.

## Что изменилось

- **Книга показывается один раз.** С полкой (iOS 99+) отдельная карточка «Что читаете» больше не
  дублирует выбранную книгу: полка и выбор книги объединены в блок «Что читаете». Выбранная книга
  подсвечена и отмечена галочкой, остальные — пустым кружком. Длинное пояснение заменено одной строкой.
- **Сохранённый подход** — одна тихая строка под кнопкой «Новый подход» вместо отдельной зелёной плашки.
- **«Приложения для чтения»** компактнее и скрываются, пока подход открыт (во время чтения их всё равно
  нельзя менять).
- **«Сегодня»:** «22,3 стр/день» больше не переносится посередине (единица мельче в той же строке);
  пустое «Книги за сегодня» не показывается; книги за день — одной строкой на книгу.
- **Снятие флага:** короче и с иконкой флага, «Ещё N дня … — и один флаг снимется».
- **«Мой рейтинг»:** два места двумя колонками («4 из 5 · по среднему темпу», «4 из 5 · по страницам»)
  вместо четырёх строк текста. Метка для VoiceOver прежняя.
- **Запись страниц после часа:** напоминание легче (без второй рамки), таймер уменьшен до 148, чтобы
  ввод страниц был главным шагом.
- Исправлена иконка-заглушка обложки: вместо кружка — книга.

## Компоненты

`ReadingTimer` (`size="compact"`), `ReadingSaveStatus` (`variant="inline"`), `ReadingBookshelf`,
`ReadingBookSummaryRow`, `ReadingAllowedAppsCard`, `ReadingProgressSummary`, `ReadingTodayBooks`,
`ReadingFlagRecovery`, `ReadingRankLink`, `ReadingChallengeContent`. Стили внутри компонентов, новые
Storybook-состояния: `Reading/Challenge` → `ShelfSaved`, `ShelfSavedDark`, `ShelfSavedLargeText`,
`ShelfRunning`, `ShelfPages`; таймер `RecordingCompact*`; статус `SavedInline*`.
