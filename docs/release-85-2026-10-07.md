EAS Submit значился Operational, поэтому причина задержки не установлена.

Готовый IPA сначала проверен `xcrun altool --validate-app`: Apple вернул
VERIFY SUCCEEDED with no errors (2026-10-07 12:39:06 UTC).
После успешной валидации отменена ровно указанная ожидающая submission;
CLI подтвердил отмену, а helper повторно проверяет CANCELED до загрузки.
Новый build не запускался.

Для прямой загрузки `xcrun altool --upload-package` используется тот же ключ,
уже назначенный этому приложению в EAS credentials service. Ключ не создаётся
и не меняется. Секрет не выводится и не сохраняется в репозиторий; временная
копия для Apple CLI имеет права 0600 в каталоге 0700 и удаляется в finally.
Загрузка использует проверенный выше IPA с тем же SHA256.

Прямая загрузка завершена: **UPLOAD SUCCEEDED with no errors**,
2026-10-07 12:42:05 UTC. Delivery UUID:
`1222606d-baa2-4119-90c3-7c4da608e89f`.
