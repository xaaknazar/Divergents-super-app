## Что вошло

- Стеклянный поиск курсов; фон, категории и заголовки обучения как в 114.
- Обложка курса во всю ширину под статус-баром, кнопки поверх, крупное название.
- Профиль: мягкий цветной фон, центральный аватар с кольцом заполнения анкеты,
  имя, email, стеклянная кнопка редактирования.
- Карта: город и страна в две строки, стеклянные поиск/фильтры/геоподсказка,
  вертикальная капсула управляющих кнопок.
- Дымчатое стекло верхних кнопок в светлой теме, белые символы без обводки;
  текстовые действия шапки единообразны, стеклянное «Изменить» у целей.
- Каналы: список и лента по референсам Telegram, без узорного фона.
  Долгое нажатие увеличивает сообщение и открывает реакции на размытом фоне.
  Отдельная кнопка эмодзи и кнопка пересылки сообщения убраны.
- В Сообществе участник видит только свой активный Reading challenge.
- Extreme/Moderate: топ-20 по среднему темпу доступен с личного 7-го календарного
  дня, день вступления считается первым (границы дней по Алматы).
  Новички остаются видны с места 21, с результатами и подсказкой срока допуска.
  Пустые защищённые места не заполняются новичками. Рейтинг по страницам без ограничения.
