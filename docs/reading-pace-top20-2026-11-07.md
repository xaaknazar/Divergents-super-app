# Reading: допуск в топ-20 по среднему темпу

Статус: реализовано и проверено локально; сервер и TestFlight не опубликованы.

## Правило владельца

В Extreme и Moderate Reading (continuous) места 1–20 по среднему темпу доступны начиная с 7-го календарного дня участия. Используется существующий серверный `daysParticipated`: день вступления — день 1, граница дня — 00:00 Asia/Almaty. Это не семь выполненных норм и не серия без пропусков. Новый день не рассчитывается по часам телефона. После выхода и повторного вступления текущий период начинается с дня 1, допуск тоже начинается заново.

Сначала выбираются 20 лучших по темпу из допущенных участников. Остальные остаются в списке, начиная с места 21, и сортируются по тому же темпу независимо от допуска. Если допущенных пока меньше 20, свободные места в топе остаются свободными. В интерфейсе число участников показано отдельно от места, чтобы не возникало «21 из 2».

При допуске место не гарантируется: участник со слабым средним темпом может остаться ниже топ-20. Все его прошлые страницы уже входят в средний темп. Рейтинг по суммарным страницам остаётся доступным без ограничения с первого дня. Обычный челлендж R/NS/Activity и scheduled Reading не изменены.

## Сервер и приложение

- Серверная копия: `/private/tmp/divergents-reading-top20-server`, ветка `codex/reading-pace-top20`, база `f02d5e4` (отчёт Reading 114).
- Мобильная копия: `/private/tmp/divergents-channel-design`, ветка `codex/channel-apple-design`; изменение поверх `78c4ed7`.
- Алгоритм в `lib/reading-pace-ranking.ts` сервера и `src/data/readingPaceRanking.ts` приложения идентичен побайтово.
- Detail возвращает `paceRankingPolicy`, а участник и `me` — `paceRank`, `paceTopEligible`, `paceTopDaysLeft`.
- Приложение использует серверные места. Для старого API или сохранённого ответа действует тот же алгоритм по серверным дням участия. Данные, страницы, время, флаги и историю он не изменяет.
- Старые поля `rankingEligible` / `rankingPending` не переиспользуются: новичок не исключается из рейтинга и не отправляется на проверку.
- Обновлены таблица, карточка своего места, «Мой рейтинг», полные правила и Storybook-состояния новичка/узкого экрана/тёмной темы. Отображается число дней до допуска.

## Проверки

- TypeScript: приложение и сервер без ошибок.
- Приложение: 60 сфокусированных тестов, 0 ошибок; генерация Storybook выполнена.
- Сервер: полный набор — 328 passed, 10 skipped, 0 failed. Пропущены проверки, требующие отдельной интеграционной БД/окружения; production для тестов не использовался.
- Новый read-only контракт вызывает настоящую `readingDetail` на in-memory adapter без методов записи: Extreme/Moderate, совпадение таблицы и `me`, просмотр наблюдателя, удаление выбывшего из топа и неизменность scheduled.
- Границы 6/7 дней, новичок с 200 страницами, больше и меньше 20 допущенных, только новички, ничьи, стабильность, сохранение всех строк и повторное вступление покрыты тестами.
- Визуальная проверка этого дополнения на физическом телефоне и симуляторе не выполнялась.

## Выпуск

Миграций и правок результатов не требуется. Для полного внедрения нужны серверный релиз и новая мобильная сборка: старое приложение самостоятельно сортирует средний темп и не знает нового правила. Один серверный релиз не исправит порядок на старых версиях. Публикация в рамках этой задачи не выполнялась.
