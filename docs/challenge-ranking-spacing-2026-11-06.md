# Отступы рейтингов — 6 ноября 2026

## Область изменения

Проверены общие компоненты рейтинга обычного челленджа (команды / участники,
за весь челлендж / сегодня / своя команда), Reading (Extreme / Moderate,
страницы / средний темп), итоговых рейтингов и просмотра для неучастников.
Это изменение отображения. Расчёт баллов, флагов, мест и порядок участников
не меняются; сервер и реальные результаты не затрагивались.

## Файлы

- `StandingsTable.tsx`: раньше адаптивное расположение применялось только
  к Reading, а ширина числовых колонок не учитывала системный размер текста.
  Теперь все рейтинги используют единую сетку заголовка и строк с промежутками
  12 pt. Ширина колонок учитывает значения, подписи и масштаб текста. При
  недостатке места показатели переходят под имя; при большом размере текста
  сами показатели могут занимать несколько строк. Место фотографии одинаковое
  во всех строках; длинным именам и подписям доступен перенос. Новых внешних
  стилевых пропсов нет, публичный API сохранён.
- `ChallengeResultRankingRow.tsx`: адаптация итогов теперь зависит от ширины
  самой строки, а не только экрана. Место, аватар и показатели имеют устойчивые
  промежутки; длинные названия и большие баллы располагаются вертикально,
  если горизонтальное расположение тесное. Числа сохраняют обычные пробелы
  из `fmtInt`: NBSP в Gotham Rounded имеет некорректную ширину. Публичный API
  сохранён.
- `ChallengeRanking.tsx`: добавлен вертикальный промежуток между перенесёнными
  значками целей дня. Данные и действия целей не изменены.
- В Storybook дополнены варианты этих компонентов: узкие команды/участники,
  дневной рейтинг, крупные значения и увеличенный шрифт.
