## Серверный выпуск

Снимок текущих tracked/untracked исходников LMS собран отдельно от рабочего
дерева в `/private/tmp/divergents-release84.BbeXrx/lms`, без локальных env-файлов.
Включены ранее подготовленные серверные изменения мероприятий, рейтингов
на сайте, видимости челленджа и синхронизации анкет.

Команда проекта Vercel содержала `prisma db push --accept-data-loss`.
Для этого выпуска она переопределена: сначала `npm run build`, затем только
`prisma db execute --file prisma/migrations/20260923_offline_event_ownership.sql
--schema prisma/schema.prisma`. Миграция добавляет nullable city/createdById
для Trip/Meetup/Sport и меняет default SportApplication.status на pending;
строки и существующие статусы не удаляются и не переписываются. Добавлены
lock_timeout 5 секунд и statement_timeout 30 секунд.

В рабочем LMS `vercel.json` теперь явно задан `npm run build`, без автоматической
смены схемы. Одноразовая команда миграции использована только в release-снимке.
При откате приложения эти добавочные колонки следует оставить, не удалять.

Временная локальная копия env, полученная от Vercel, удалена. Значения DATABASE_URL
и DIRECT_URL Vercel не раскрыл; миграция выполнена в серверном окружении Vercel.
