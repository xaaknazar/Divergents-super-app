# Reading: пять красных флагов — выбывание, возврат с нуля

4 ноября 2026. Сервер: ветка `codex/reading-five-flags` (от `codex/challenge-team-order`, production-источник
Reading 107 + порядок команд). Приложение: `reading-five-flags` (от `codex/reading-year-modes`, TestFlight 107).
Не выкачено и не опубликовано.

## Правило

Только годовые (continuous) челленджи — Extreme и Moderate. Командные (scheduled) не меняются: там по-прежнему 3 флага.

- Когда у участника **одновременно 5 красных флагов** (уже снятые за серии не считаются), участие завершается
  в этот день: `eliminatedOn` = день пятого флага.
- Результат замораживается на этом дне: дни, страницы, темп и флаги после него не считаются.
- Участник пропадает из рейтинга (`ranking`, `participants`), но сам видит свой замороженный результат (`me`).
- Новый подход начать нельзя: `start` → `eliminated` «5 красных флагов: участие завершено. Можно начать заново — с нуля.»
  Страницы уже начатых подходов за дни до выбывания можно дописать.
- Вернуться: существующие `leave` (сброс с аудитом) + `join` — новый день 1, ноль страниц и флагов.
- Выбывший не занимает «одно место» в годовых челленджах: можно вступить в другой режим.
- Правило действует и задним числом: кто уже держит 5 флагов, выбывает сразу после выката. Данные при этом не
  удаляются и не меняются — выбывание вычисляется. Сброс происходит только по кнопке «Начать заново».

## Изменения сервера

- `lib/reading-continuous-policy.ts`: `READING_ELIMINATION_FLAGS = 5`, `eliminatedOn`, заморозка записи.
- `lib/reading-service.ts`: рейтинг без выбывших, `me` из полного списка, `eliminationFlags: 5` в деталях,
  сообщение отказа старта, проверка «одного годового челленджа» без выбывших участий.
- Миграции не нужны.

## Приложение

- Вместо таймера — карточка «Вы выбыли из челленджа» и «Начать заново» (подтверждение → `leave` → экран вступления).
  Показывается, только если сервер прислал `eliminationFlags`; иначе — прежнее «Участие завершено на N-й день».
- В блоке снятия флага: «Ещё N флага — и участие завершится» (красным, когда осталось ≤ 2).
- Правила: пункт про флаги дополнен выбыванием и возвратом с нуля (тоже только при `eliminationFlags`).

## Порядок выката

Сначала сервер, потом сборка. Старые сборки (107) с новым сервером: выбывший видит «Участие завершено»,
без таймера; вернуться может через «Покинуть челлендж» и повторное вступление.
