# Revolut Business — внедрение в Divergents, 7 октября 2026

## Направление и источники

Пользователь выбрал конкретный референс и попросил внедрение. Старый рандомизированный выбор макета не считается согласованием; новый прямой запрос определяет направление.

Просмотрены изображения через Mobbin MCP, не только описания:

- [Главная / виджеты](https://mobbin.com/screens/41c74abd-3820-4130-b6b9-b08b7a5a77f4): спокойные крупные блоки, круглые пиктограммы, плотная группировка данных внутри и воздух между блоками.
- [Список операций](https://mobbin.com/screens/7b451837-103e-44be-9d06-4ffa97f48f4e): объединённые строки без рамки вокруг каждой строки.
- [Профиль компании](https://mobbin.com/screens/6cd7dc82-a700-4f58-bfff-6d692349ad24): крупный заголовок, сгруппированные пункты, круглая кнопка возврата.
- [Профиль](https://mobbin.com/screens/44e2d1f6-31c3-4fb3-b0db-4fba84ad158d): подписи секций обычным регистром, мало декоративных разделителей.

Не перенесены чужие логотипы, банковские данные, функции и растровые материалы. Светлая тема — адаптация этого языка, а не заявление о точном воспроизведении светлого экрана источника. Сохранены Gotham Rounded, фирменный синий, настройки акцента/фона и обе темы.

## Реализованный слой

Общие токены и примитивы используются во всех пяти вкладках и вложенных маршрутах. Кроме этого, переработаны конкретные композиции сообщества, AI, профиля и управления картой. Карьера остаётся честным экраном «скоро», не получает выдуманные вакансии. Спортивная логика и Luma-результат создания не переписаны.

Это **не** утверждение, что каждый старый экран полностью очищен от inline-стилей. Глобальный архитектурный рефакторинг старого UI ещё имеет хвосты. Здесь внедрены общий визуальный слой и перечисленные ниже блоки; нельзя выдавать это за ручной визуальный аудит всех маршрутов.

## Storybook и проверка

Новые компоненты снабжены историями светлой/тёмной темы и узкого экрана с крупным текстом. Изолированный CommunityPreviewProvider использует явно обозначенные demo-данные без API и аккаунтов; добавлены только экспорты существующих React-контекстов, работа production-провайдеров не изменена.

- TypeScript: проходит.
- Jest: 57 suites / 416 tests проходят до финального review.
- Storybook registry: сгенерирован.
- Native visual QA: **не завершён**. Simulator доступен, но Expo Go не загрузил локальный проект; координатное управление сообщает noWindowsAvailable. Скриншот окна Expo Go не является доказательством качества приложения.
- Android/iOS production JS/Hermes bundles: успешно экспортированы командой `EXPO_PUBLIC_STORYBOOK_ENABLED=false npx expo export --platform ios --platform android --output-dir /tmp/divergents-revolut-export-20261007`. Это проверка упаковки приложения, не нативная сборка для магазина.
- Независимый Impeccable finish review: `recapture`. Без настоящих снимков приложения визуальное одобрение не выдано; Expo Go launcher/error не считается проверкой дизайна.
- Статический архитектурный аудит: 51 экран, 3 без замечаний, 2543 оставшихся замечания; истории есть у 64 из 89 файлов компонентов. Все новые компоненты этого изменения имеют истории. Полный рефакторинг старых экранов и покрытие старой библиотеки Storybook ещё не завершены.
- TestFlight / App Store / backend: не публиковались в этой задаче.

Нельзя утверждать пиксельное соответствие или адаптивность всех экранов без настоящих native-снимков и проверки на устройствах.
