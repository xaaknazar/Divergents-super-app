# Плавающая активная капсула таб-бара

Готовая анимация из `c28d275` перенесена поверх ветки выпуска `reading-108`
после отчёта сборки 109 (`872a59d`). В уже опубликованном IPA 109 её нет;
эта правка предназначена для следующей сборки. Номер приложения не менялся.

## Поведение

- Одна активная капсула скользит между вкладками через Reanimated `withSpring`.
  Повторное быстрое переключение перенаправляет текущую анимацию.
- Первое измерение панели, изменение ширины или набора видимых вкладок
  устанавливают положение сразу. Учитывается направление RTL.
- «Уменьшение движения» отключает spring; изменение настройки применяется
  без повторного открытия панели.
- Капсула не перехватывает касания и не дублирует элементы VoiceOver.
  Действующие цвета, размеры, иконки, мини-плеер и маршрутизация сохранены.
- Внешний API TabDock не расширялся: визуальные стили и анимация находятся
  внутри компонента. Storybook показывает движение в светлой/тёмной теме,
  компактную панель, уменьшенную прозрачность и отдельный ReducedMotion.

## Проверки

- TypeScript: без ошибок.
- TabDock и TabBar: **18 тестов прошли**. Добавлены проверки быстрых переключений,
  изменения размеров/видимых вкладок и переключения Reduce Motion на открытой панели.
- Физическая плавность на iPhone в этой задаче не проверялась.
- Сервер, результаты участников и исходники опубликованного IPA 109 не менялись.
