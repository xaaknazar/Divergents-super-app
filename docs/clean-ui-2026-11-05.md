# Чистка интерфейса: чтение, «Мои книги», команда, каналы

5 ноября 2026. Ветка `reading-108` (сборка 109). Только интерфейс: API, сервер и правила
не менялись. Не опубликовано. Все четыре правки приняты на странице выбора (до/после).

## Что изменилось

- **Экран чтения.** «Статистика», «Мой рейтинг», «Мои книги и история» — одна карточка-список
  (`ReadingLinksGroup`) с одинаковыми строками и цветными иконками, без теней. Места в рейтинге —
  одной строкой «4 из 5 по страницам · 4 из 5 по темпу», части переносятся целиком.
  В годовом челлендже под «Статистикой» больше нет полоски прогресса года (она на экране
  статистики). `ReadingRankLink` и `ReadingHistoryLink` удалены; итоговая карточка завершённого
  года (`ReadingJourneyCard completed`) осталась.
- **«Мои книги».** Действие «✓ Готово» в цвете приложения вместо зелёной «✓ Прочитана», которая
  выглядела как поставленная отметка. Строка «Reading · 96 стр. · 5 ч 12 мин» переносится частями;
  ровные часы — «2 ч» вместо «2 ч 0 мин». Вступление короче. `MyBookRow`, `data/myBooks.ts`.
- **Команда челленджа.** Плашка движения места — только когда место изменилось. Флаги — одна плашка
  с разбором («чтение 1 · сахар 1 · шаги 1»). Медаль — рядом с именем. `ChallengeDetailScreen`.
- **Каналы.** Название в две строки, подпись словами «3 поста · открытый», кнопка «Открыть» /
  «Запрос» уже. `CommunityChannelRow`, `ChannelsScreen`. При самом крупном шрифте длинное слово
  может перенестись по частям.
