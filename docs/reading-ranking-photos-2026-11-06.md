# Фотографии в рейтинге Reading — 6 ноября 2026

Статус: исправление подготовлено и проверено, не опубликовано.

Причина: Reading API выбирал имя без User.photoUrl; схема приложения не
сохраняла поле фотографии, а ReadingRankingContent передавал avatar: null.
В карточке «Ваше место» также явно использовалось пустое фото.

Приложение сохраняет необязательное поле avatar из ответа API и передаёт
его в существующий MemberAvatar. Если фото отсутствует или не загрузилось,
остаётся первая буква имени. На узком экране показатели переносятся под имя,
фотография не скрывается ради ширины колонок. Обе вкладки рейтинга сохраняют
одинаковые данные и навигацию. Добавлены примеры Storybook с фото.

Серверная часть подготовлена отдельно от production 9e88a86 в ветке
codex/reading-ranking-avatars, рабочая копия
/private/tmp/divergents-reading-avatars-server. Поле avatar берётся из
User.photoUrl через общий publicAvatar одним запросом на всех участников.
Миграций, новых API-запросов на каждого участника и изменений результатов нет.

Проверки:
- TypeScript приложения и сервера: без ошибок.
- Приложение: 20 тестов рейтинга/данных прошли, включая парсинг фото из API,
  собственную карточку, смену режима и узкую таблицу.
- Сервер: 320 тестов прошли, 9 пропущены (требуют отдельную БД), 0 ошибок.
- Нативный предпросмотр iOS 26.5 Simulator: фотографии загружаются, запасная
  буква видна при отсутствии фото, обе таблицы сохраняют фото на ширине 320.
- Физический iPhone не проверялся; production и TestFlight не менялись.

Порядок будущего выпуска: серверное добавление avatar, затем новая мобильная
сборка. Старые клиенты игнорируют добавочное поле; новый клиент совместим со
старым сервером, но до его обновления будет показывать инициалы.
