  четыре главных правила при вступлении, статистика недели, календаря и книг.

  дня без обрезки.
- «Статистика / Мой рейтинг / Мои книги» собраны одним списком; в «Моих книгах»
  есть «Готово»; меньше плашек у участников, названия каналов показаны целиком.
