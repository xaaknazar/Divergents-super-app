## Поведение

- В обычном Divergents Challenge ввод страниц открывает форму «Чтение».
  Нужны книга и автор; книга сразу выбирается после добавления. Страницы
  учитываются по книге. «Я дочитал(а) эту книгу» завершает её; после сохранения
  можно выбрать следующую. Прежние страницы без книги сохраняются отдельно.
- С началом офлайн-встречи организатор видит «Отметить участников» внутри
  мероприятия, спорта или поездки. Только принятые участники: ✅ Пришёл,
  🪱 Опоздал, ☠️ Не пришёл. Отметка сохраняется сразу, комментарий необязательный;
  статус и комментарий можно исправить. Автоматических неявок нет.
- Исправление подтверждения добавления книги в Extreme/Moderate из 124 сохранено.
