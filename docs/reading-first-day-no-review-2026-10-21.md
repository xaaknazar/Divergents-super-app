# Reading: рейтинг с первого дня и результат без модерации

## Статус

Подготовлено локально 21 октября 2026. Production, TestFlight и номер
сборки не менялись. Проверка на физическом устройстве в рамках этой задачи
не проводилась.

## Правила

- Участники получают место с первого дня участия. Порядок: средний темп
  в страницах за календарный день участия, затем длительность участия,
  затем стабильный идентификатор. Дни без чтения остаются в знаменателе.
- Результат больше не ожидает отдельного решения администратора.
  Проверка существования книги остаётся отдельной функцией.
- Пауза останавливает время и снимает ограничения, возобновление продолжает
  тот же подход. До выполнения дневных 60 минут нельзя вручную закончить
  обычный подход и перейти к страницам — ни из UI, ни через hook, ни через Swift.
- После цели можно продолжать чтение либо поставить паузу и сохранить страницы.
  Если часть часа уже была сохранена, требуется только оставшееся время.
- Вынужденное окончание при границе суток/прерывании сохраняет фактическое
  частичное время. Оно не превращается автоматически в выполненные 60 минут.
- Сохранение на телефоне и подтверждение сервером по-прежнему различаются;
  сбои сети не удаляют очередь отправки.

## Код

- `src/data/reading.ts`: правила и сортировка без списка ожидающих допуска.
- `ReadingChallengeContent`: без блокировки дня по `review`, ввод страниц
  только после цели для возобновляемой паузы.
- `ReadingRankLink`, `ReadingRankRow`, `ReadingSaveStatus`: убраны устаревшие
  визуальные пропсы проверки; Storybook обновлён.
- Неиспользуемые `ReadingReviewPanel` и его story удалены из рабочей копии;
  прежний код остаётся в Git.
- `useReadingChallenge`: запрет преждевременного finish, удалены неиспользуемые
  клиентские действия модерации. Нативные ownership/generation-проверки сохранены.
- `ReadingFocusStore.swift`: пауза не обходит обязательный час; прежняя логика
  Live Activity, разрешений и снятия блокировок сохранена.
