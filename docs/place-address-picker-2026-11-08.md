# Поиск адреса при предложении места

В форме нового места и редактирования добавлен PlaceLocationPicker: ручной ввод улицы и номера дома, явная кнопка поиска, приближение к найденной точке и уточнение перетаскиванием метки. Используется существующий expo-location (системный геокодер), без новых библиотек и серверного выпуска.

Сохраняются координаты выбранной точки, как и раньше. Введённая поисковая строка не становится отдельным полем адреса в базе. Текст результата просит проверить положение: геокодер может найти улицу без точного дома. Карта standard с отображением зданий, высота 280, начальное приближение 0.008, после поиска 0.003. Наличие номеров домов зависит от картографических данных; принудительного добавления отсутствующих номеров нет.

Поиск не запускается при каждом символе. Изменение запроса, ручная установка метки и уход с экрана делают устаревший ответ недействительным. Через 12 секунд интерфейс прекращает ожидание; поздний ответ не меняет метку. На Android системный геокодер требует foreground permission; при отказе остаётся ручная карта. iOS не запрашивает геолокацию для этого поиска.

Проверки: npm run typecheck без ошибок; 8 тестов поиска и взаимодействия прошли (успех, неверные координаты, отказ Android, отсутствие адреса, ручная метка во время поиска, новый запрос и таймаут). Storybook: Light/Dark. На физическом устройстве не проверялось. В TestFlight ещё не опубликовано.
