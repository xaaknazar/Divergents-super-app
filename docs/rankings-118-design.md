# Рейтинги 118

Одобренный макет: круглые номерные медали золото/серебро/бронза у мест 1–3. Команды без фото, инициалов и логотипов. Участники с публичным фото, инициалы при отсутствии/ошибке. При смене URL фото повторно загружается.

Общая таблица разделяет имя, движение и результат. В Reading второй показатель под основным, флаги под именем. На узком экране и при крупном тексте значения переносятся целиком. Нет блока «Ваша команда» и дополнительного слогана.

Движение вычисляет сервер по сохранённым результатам: прежнее место минус текущее. Для Reading метрики независимы; календарь Алматы, допуск к темпу с седьмого календарного дня. Новичок без истории не получает фиктивную стрелку. Это пересчёт исторических результатов, а не неизменяемый снимок: исправления вчерашних страниц обновят базу сравнения. Новых таблиц/ежедневных записей не требуется.

«Сегодня» сравнивается с дневными результатами вчера, отдельно от общего зачёта. Фильтр своей команды сохраняет глобальные места. Итоговый рейтинг сравнивается с предпоследним днём и не зависит от сегодняшней даты. Состав команды сравнивается внутри команды.

Публичный API зрителя получает только фото и движения, без анкет, контактов и истории отметок. Итоговые баллы не меняются.

Компоненты RankMedal и RankMovement имеют семантические параметры rank/change; стили внутри. Добавлены Storybook-примеры. Физическая проверка владельцем отложена.
